# H3, second form (design §4.2, claim resolution):  a reader the
# publisher put in I2's count dies;  I2 is removed while counted,
# leaving a tracking-only instance head, and the expirer takes over the
# dead publisher's publish.  The search from this prefix covers it.
# Run:
#   FSIO_MODEL_VERSIONED=1 FSIO_MODEL_VSTART=null FSIO_MODEL_ROLES=wr
#   FSIO_MODEL_S3_OPS=1 FSIO_MODEL_SHORTEST=1 FSIO_MODEL_PREFIX=<this file>
# Skip H3_PUBLISHER_HINTS_READERS to see the count left, or
# H3_TRACKING_ONLY_IS_REMOVED to see it resolved only once the count
# drains (or never, with the first skipped too).
gw1 read-olh-write
gw1 open-write null
gw1 ready S1.10
gw1 write S1.10
gw1 close-write S1.10
gw1 publish-hint
gw1 placeholder I2
gw1 partition
gw2 read-olh-read
gw2 open-read null
gw2 follow S1.10
gw1 close-leave S1.10
